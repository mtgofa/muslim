تطبيق أندرويد بسيط وعصري: **الأذان في وقته دائماً**، و**مصحف المدينة بألوان التجويد** مع تلاوات
كبار القرّاء والتكرار. بدون إعلانات، بدون حساب، وواجهة عربية كاملة.

## المميزات

### الصلاة والأذان
| | |
|---|---|
| **الموقع** | تلقائي بالـ GPS أو باختيار المدينة/المحافظة (كل محافظات مصر + أهم مدن العالم العربي والإسلامي). |
| **طرق الحساب** | الهيئة المصرية العامة للمساحة (افتراضي)، رابطة العالم الإسلامي، أم القرى، كراتشي، أمريكا الشمالية، الخليج، تركيا، فرنسا — والعصر شافعي أو حنفي. |
| **تعديل الوقت** | قدّم أو أخّر كل صلاة بالدقائق لتطابق مسجدك. |
| **تنبيه قبل الأذان** | مدة مستقلة لكل صلاة (أو إيقاف)، بصوت «سبحان الله». |
| **تنبيه الإقامة** | مدة مستقلة لكل صلاة بعد الأذان، بصوت «سبحان الله». |
| **المؤذنون** | عبد الباسط عبد الصمد والحرم المكي مدمجان، و١٢ صوتاً آخر (محمد رفعت، المنشاوي، نعينع، العفاسي، القطامي…) تُنزّل مرة واحدة — مع صوت مختلف للفجر اختيارياً. |
| **صفحة الأذان** | تظهر فوق شاشة القفل، ويوقفها زر الصوت أو زر الإيقاف. |
| **التاريخ الهجري** | أم القرى مع تعديل ±يومين حسب رؤية الهلال. |

### الأذان لا يتوقف
- منبّه دقيق (`setAlarmClock`) للحدث القادم فقط، يُعاد تسليحه بعد كل أذان، وبعد إعادة التشغيل، وتغيير الوقت أو المنطقة الزمنية، وتحديث التطبيق.
- إشعار دائم هادئ بالصلاة القادمة وعدّاد تنازلي (خدمة أمامية) يمنع النظام من إغلاق التطبيق.
- الأذان يُشغَّل على قناة **المنبّه** (يُسمع حتى لو صوت الوسائط مقفول)، ويتوقف أثناء المكالمات (اختياري).
- شاشة «ضمان عمل الأذان» تفحص الإشعارات، قيود البطارية، المنبّهات الدقيقة، وتفتح إعدادات «التشغيل التلقائي» لشاومي/أوبو/فيفو/هواوي/سامسونج.

### المصحف
- صفحات مصحف المدينة (١٤٣٩هـ) بالخط الأصلي سطراً بسطر، **بألوان التجويد** أو بدونها، ووضع ليلي.
- الفهرس: السور، الأجزاء، العلامات، والبحث في نص الآيات.
- اضغط أي آية: تشغيل من هنا، تكرار الآية، تكرار مقطع، حفظ علامة، نسخ، مشاركة.
- المشغّل: ٣١ قارئاً (عبد الباسط مرتل ومجوّد، المنشاوي، الحصري والمعلّم، مصطفى إسماعيل، الطبلاوي، البنا، العفاسي، السديس، الشريم، المعيقلي…)، تمييز الآية الجارية وتقليب الصفحات تلقائياً، تكرار كل آية حتى ٢٠ مرة، وتكرار المقطع مرات أو بلا توقف، والسرعة، والتحكم من شاشة القفل.
- تنزيل أي سورة للاستماع بدون إنترنت.

## التحميل

من صفحة [**Releases**](https://github.com/mtgofa/muslim/releases/latest) نزّل `Muslem.apk` وثبّته.
التطبيق **يحدّث نفسه** — يظهر تنبيه عند صدور نسخة جديدة، ويمكن الفحص يدوياً من «حول التطبيق».

عند أول فتح للمصحف تُنزَّل حزمة صفحات المصحف (~٧٠ م.ب) مرة واحدة فقط، فتبقى تحديثات التطبيق صغيرة.

## البناء من المصدر

```bash
# JDK 17، Android SDK (platform 34)، Gradle 8.9 (عبر ./gradlew)
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease     # موقّع بمفتاح keystore.properties (خارج Git)
```

### النشر والتحديث التلقائي

```bash
tools/release.sh bump "ملاحظات الإصدار"   # يزوّد versionCode/versionName، يبني، وينشر Release
tools/release.sh pack                      # ينشر حزمة صفحات المصحف (مرة واحدة / عند تغييرها)
```

عقد التحديث: اسم الإصدار يحتوي `(code N)`، والملف `*.apk`، والوصف فيه سطر `sha256: …` يتحقق منه
التطبيق قبل فتح المثبّت. حزمة المصحف منشورة كـ prerelease بوسم `mushaf-v1` فلا تُعتبر «أحدث إصدار».

### المحتوى القابل للتعديل (بدون إصدار جديد)

مجلد `content/` فيه: `adhkar.json` (حصن المسلم)، `tasbeeh.json` (عبارات السبحة)، `reciters.json`
(القرّاء)، `muezzins.json` (المؤذنون). الملفات دي مدمجة في التطبيق فيشتغل أوفلاين، وفي نفس الوقت
التطبيق بيفحص نسختها على GitHub (فرع `main`) كل ٦ ساعات تقريباً؛ أي تعديل يتعمل push على `content/`
بيوصل للموبايلات تلقائياً من غير ما تنزّل إصدار. لإعادة توليد الأذكار من المصدر:
`python3 tools/build_adhkar.py`.

### بيانات المصحف

`tools/build_quran_data.py` يولّد `app/src/main/assets/quran.db` (نص الآيات، تخطيط الصفحات والأسطر،
السور، الأجزاء، الأرباع) وخط عناوين السور، ويضع خطوط الصفحات الـ ٦٠٤ في `dist/mushaf-pack/`.

```
app/src/main/java/com/mtgofa/muslem/
  MainActivity.kt            التنقل، الترحيب، نافذة التحديث
  prayer/PrayerCalc.kt       الحساب الفلكي للمواقيت
  prayer/Scheduler.kt        الأحداث (قبل الأذان، الأذان، الإقامة) والمنبّه الدقيق
  prayer/AdhanService.kt     تشغيل الأذان و«سبحان الله» على قناة المنبّه
  prayer/KeepAliveService.kt الإشعار الدائم بالصلاة القادمة
  prayer/AlarmReceiver.kt    استقبال المنبّه، وإعادة التسليح بعد الإقلاع
  quran/MushafPage.kt        رسم الصفحة سطراً بسطر بخط الصفحة الملوّن
  quran/MushafFonts.kt       اختيار لوحة الألوان (تجويد/عادي، نهاري/ليلي)
  quran/QuranPlayer.kt       خدمة التلاوة وقوائم التكرار
  data/Updater.kt            التحديث الذاتي من GitHub Releases
  ui/                        الشاشات
```
